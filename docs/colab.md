# Colabデモ

[demo.ipynb](../notebooks/demo.ipynb)をColabのノートブックアップロードから開きます。
新しい標準CPUランタイムを使用してください。
Python 3.11〜3.13が必要です。
環境の選択方法は[Colab公式のランタイム案内](https://research.google.com/colaboratory/runtime-version-faq.html)で確認できます。

1. ローカルの`shogi-human-policy`ディレクトリで`uv build --wheel`を実行します。
2. 最初のセルで、生成したwheel、`manifest.json`、`policy.safetensors`の3ファイルをまとめてアップロードします。
3. 入力方法を選び、SFENやUSI文字列を貼り付けるか、棋譜ファイルをアップロードします。
4. 何手指した後を使うか指定し、表示された盤面と手番を確認します。
5. 先手と後手のR、必要ならその局面の時計を指定して、予測セルを実行します。

空欄の手数は末尾、0は開始局面です。
時計とRはチェックを外すと不明として扱い、既知の0秒とは区別します。
先手と後手の値は、選んだ局面の手番に応じて自分と相手へ自動で振り分けます。
局面を変更したら、表示セル以降も再実行してください。

表示するのは盤面と、上位候補の日本語表記、USI表記、確率です。
確率は全合法手に対する値で、表示した候補だけで100%になるとは限りません。

公開用の配布先が決まるまでは、wheelとモデルを手元からアップロードして利用します。
