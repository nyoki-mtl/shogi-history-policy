# モデルの来歴

## 前作との関係

作者の前作は[nyoki-mtl/maia2-shogi](https://github.com/nyoki-mtl/maia2-shogi)です。
棋力条件に応じた人間の着手を予測する取り組みを引き継ぎ、本モデルではrsshogi-azの学習済み重みからAdaLN付きモデルを学習しています。
R、時計、局面履歴を入力でき、それぞれの寄与も検証しています。
公開されている前作v0.2.1との[同一局面での予測性能比較](direct-comparison.md)を用意しています。

## ローカル準備版

| 項目 | 内容 |

| 選択 | 605,000更新時点のEMA |

| 学習対象 | 1,903,880,882局面、自然な出現頻度 |
| 予定更新数 | 3,718,518更新、batch 512、1 epoch |

| 学習対象のhead | 人間の着手を教師とするpolicy |

学習は継続中です。
このsnapshotは全データを1周した最終モデルではありません。
学習対象から評価用対局と同一着手列の重複を除外しています。
棋力帯、持ち時間形式、手数帯による均等化やoversamplingは使いません。
Rと時計が不明な対局でも、利用できるpolicy教師は残し、条件をmaskします。

条件dropoutは「両方使用70%、Rのみ10%、時計のみ10%、両方省略10%」です。
履歴は8局面50%、現在局面だけ25%、2〜7局面を各1/24で使用します。
これらはfine-tuning開始時から適用しています。

構造はLc0とBT4系の設計を参照したrsshogi-az-trainerの95 token Transformerを基にしています。
本リポジトリの推論は、その学習済み重みと同じ計算をPyTorchで実装しています。
JAX/Flaxの学習実装を実行時依存に含めません。
個人の棋風を識別して再現する学習や、指定Rでの対局棋力の校正は行っていません。

## 検証範囲

CPU float32の実モデルをJAXと比較し、48通りの局面と条件でlogitの最大絶対差は`3.0517578125e-05`でした。
Rのみ、時計のみ、両方、不明の条件と、先後、成り、駒打ち、履歴短縮を含みます。
別途、小型モデルの固定JAX出力でQK正規化と非ゼロAdaLNの回帰テストを行います。
学習時TPUのBF16とCPU float32の評価値は、丸めの違いにより完全一致しません。
R帯を揃えた追加評価ではCUDA float32（TF32無効）を使用しました。
128局面のCPUとの比較で、着手確率の最大絶対差は`1.24e-6`未満、第一候補は全件一致しました。
これは限定した入力での確認で、GPU全般の性能保証ではありません。
ONNX、指定レーティングでの対局棋力は未検証です。
